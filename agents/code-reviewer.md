## 必查项：断言强度核对（**复发类问题，2026-10-16 固化，跨线适用**）

> 触发事实：① 本仓 `52bcb08` —— cutover 「重扫不重注」断言因**漏 `await flush()`** 而**恒真**（假绿）；
> ② GreenCAD P1 的 L4（`plans/20261016_s1_p1_L4_review.md`）L4-01/L4-02 —— 断言名义强于实际
> （只遍历已解析集合、未做**可达性**分析、存在**整文件排除**）。⇒ 属复发类，必须逐条核。

**逐条断言回答三问（不允许只给定性印象）**：

1. **覆盖面对不对**：它实际覆盖的是「名义全集」还是「**实际能走到的子集**」？
   （典型：只遍历已注册/已解析集合、只扫白名单内文件、只测 happy path、断言在**异步回写前**读结果）
2. **是不是弱化替代**：是否存在
   - **整文件 / 整目录排除**（如 `ProductionEntryFileNames` 之外仍排除 4 个文件）；
   - 只比对**类型/形状**而非**行为**；
   - 只做**静态遍历**而非**可达性**（调用边）分析；
   - 只读**内存对象**而非**盘上/线缆上的真实结果**。
3. **有没有反例自检**：临时**故意制造违规**（或临时还原被修掉的 bug）**必须变红**；不允许只证「正向能过」。

**补充五条（2026-10-16 第二批，跨线复用）**：
4. **观测点可证伪**：反例自检之外，还要证明该观测点在**另一情形能取非零/非默认值**（例：「取消时 `WriteAsync` Times.Never」必须配「正常路径 Times.Once」，否则写路未被调用也会绿）。
5. **全称判断指到断言**：报告里每个「全/无/均/仅/零」都要能指到一条**会变红**的断言；否则降级为事实描述并写明**排除边界**（整目录排除后的「全绿」不算全称证明）。
6. **变异恢复可验**：恢复后给**字节级证据**（sha256 相同 / `git diff` 空 / 关键字零残留）。
7. **增量归属用提交粒度**：判「哪一笔引入」用 `B^..B`；跳多提交、或文件在 A 时不存在（整文件新增）**不得**用于归属。
8. **交付不得静默截断**：任何长度上限截断必须**显式标记** + **全文落盘** + 工具层**警告发送方**（静默截断 = 静默丢失 = 未达）。

**通用门**：凡「**必红/必失败**」类断言，**先证它真能红**（无违规时故意造一条违规，确认变红）；造不出变红 ⇒ 该断言无效。

**硬性要求（新写的回归/守卫测试）**：
- **至少一条反例自检**（「故意破坏 ⇒ 必须红」），并在**测试名或注释**里标明哪一条是反例自检；
- 若无法做反例（如外部环境不可控），必须在报告里**写明「未做反例 + 原因」**，不得静默跳过；
- 审查报告中逐条给出三问的答案与**你自跑的命令/数值**；发现假绿/弱断言一律记为 finding（带 file:line）。
